# Historias de Usuario

## Mentelyx

Las historias de usuario describen las necesidades del sistema desde la perspectiva de sus usuarios.

Se utiliza la estructura:

Como [actor], quiero [acción], para [beneficio].

## Historias del estudiante

| ID | Historia de usuario |
|---|---|
| HU-01 | Como estudiante, quiero registrarme con una cuenta personal y seleccionar mi nivel educativo, para utilizar Mentelyx sin depender de una institución. |
| HU-02 | Como estudiante, quiero realizar una evaluación diagnóstica, para identificar mis conocimientos y los temas que necesito reforzar. |
| HU-03 | Como estudiante, quiero recibir una ruta de aprendizaje personalizada, para estudiar según mis necesidades y desempeño. |
| HU-04 | Como estudiante, quiero consultar contenidos organizados por nivel, área y tema, para encontrar los recursos que necesito. |
| HU-05 | Como estudiante, quiero resolver ejercicios y recibir pistas y retroalimentación, para comprender mis errores y mejorar mi aprendizaje. |
| HU-06 | Como estudiante, quiero realizar simulacros y consultar mis resultados, para evaluar mi preparación. |
| HU-07 | Como estudiante, quiero consultar mi progreso e historial académico, para reconocer mis avances y dificultades. |
| HU-08 | Como estudiante, quiero consultar los planes y gestionar mi suscripción, para acceder a los beneficios que se ajusten a mis necesidades. |
| HU-09 | Como estudiante beneficiario de un convenio, quiero acceder a los beneficios autorizados, para utilizar recursos gratuitos limitados u obtener descuentos. |
| HU-10 | Como estudiante, quiero consultar perfiles y videos demostrativos de docentes, para elegir a quien pueda ayudarme. |
| HU-11 | Como estudiante, quiero reservar y pagar una tutoría individual o grupal, para recibir acompañamiento educativo. |
| HU-12 | Como estudiante, quiero consultar mis tutorías y solicitar su cancelación cuando corresponda, para organizar mi participación. |

## Consideraciones

Las funciones administrativas estarán disponibles según los permisos asignados a cada cuenta.

En la etapa inicial, el propietario ejercerá estas funciones mediante el rol de superadministrador.

Los precios, comisiones, beneficios específicos y condiciones de cancelación deberán definirse antes de implementar las operaciones correspondientes.
